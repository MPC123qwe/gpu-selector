国产 GPU / AI 加速卡选型助手

基于商汤token plan 搭建的一个面向国产 GPU、AI 加速卡、NPU 与智算服务器场景的交互式选型展示网站。

本项目围绕国产 AI 加速硬件选型需求，整合国产 GPU / NPU 产品数据、场景化选型知识库、热点新闻数据和 AI 咨询入口，帮助用户快速了解不同国产加速卡的产品定位、关键参数、典型应用场景和对标关系。

在线访问

项目已通过 GitHub Pages 部署：

https://mpc123qwe.github.io/gpu-selector/
项目定位

随着大模型推理、AI 训练、边缘视频分析、云桌面、智算中心和国产化替代需求不断增加，GPU / NPU / AI 加速卡选型变得越来越复杂。

不同厂商、不同型号产品在以下方面差异明显：

算力类型
显存容量
功耗水平
卡型规格
服务器适配条件
软件生态成熟度
训练 / 推理 / 边缘 / 视频 / 云桌面等场景适配能力
与 NVIDIA T4、L4、A10、A100 等产品的对标关系

本项目希望把分散的国产 AI 加速卡信息整理成一个更直观、更适合展示和咨询的网站，让用户不只是“看参数表”，而是能够围绕具体场景进行初步选型判断。

核心功能
1. 国产 GPU / AI 加速卡产品展示

网站内置国产 GPU / AI 加速卡结构化数据，通过卡片化方式展示产品信息。

产品信息包括：

产品型号
厂商名称
产品定位
算力参数
显存规格
功耗信息
典型应用场景
对标产品
推荐说明

相比传统 Excel 表格，卡片化展示更适合快速浏览、对比和演示。

2. 搜索与筛选

网站支持基于关键词的产品检索和筛选，用户可以围绕以下维度快速查找产品：

厂商
型号
功耗
显存
应用场景
产品定位
对标 NVIDIA 产品
训练 / 推理 / 边缘 / 视频 / 云桌面等方向

该功能适合用于：

售前方案初筛
国产 GPU 调研
AI 加速卡对比
智算服务器配置参考
国产化替代分析
3. 场景化选型

项目不仅展示产品参数，也关注不同业务场景下的选型逻辑。

典型场景包括：

边缘视频分析
AI 推理服务器
大模型推理
智算中心
云桌面
云游戏
视频编解码
本地私有化部署
国产化替代

用户可以结合功耗、显存、算力、卡型和应用场景，快速判断哪些产品更适合当前需求。

4. AI 咨询助手

网站集成 AI 咨询入口，用户可以用自然语言描述自己的需求，例如：

我想做边缘视频分析，推荐什么国产加速卡？
150W 以内有哪些适合推理的国产 GPU？
哪些国产卡可以对标 NVIDIA T4？
我要做智算服务器方案，应该怎么选卡？
国产 GPU 里面哪些更适合视频编解码场景？

AI 咨询助手可以结合产品数据和知识库内容，给出更接近实际业务场景的推荐思路。

5. 热点新闻与行业动态

项目包含新闻数据文件，用于展示国产 GPU、AI 芯片、智算中心和大模型基础设施相关动态。

新闻模块可以辅助用户了解：

国产 GPU 厂商动态
AI 芯片行业新闻
智算中心建设趋势
产品发布信息
生态适配进展
国产化替代方向

文件说明
index.html

网站主入口文件。

GitHub Pages 会直接加载该文件作为首页，用于展示国产 GPU / AI 加速卡选型网站。

assets/

前端构建后的静态资源目录。

当前主要包含：

index-DOxD74Ku.js
index-VF9f4CM7.css

其中：

.js 文件负责页面交互逻辑、数据加载、搜索筛选和内容渲染
.css 文件负责页面样式、布局和视觉效果
images/

网站图片资源目录。

当前包含三个场景图：

scene-edge.jpg
scene-training.jpg
scene-video.jpg

这些图片可用于展示边缘计算、训练场景、视频分析等典型应用方向，增强页面的场景化表达。

gpu_data.json

国产 GPU / AI 加速卡核心产品数据文件。

该文件是网站产品展示和选型分析的重要数据来源，主要用于存储不同国产加速卡的结构化信息。

可能包含的字段包括：

型号
厂商
产品定位
算力
显存
功耗
应用场景
对标产品
推荐理由
knowledge_base.json

AI 咨询助手使用的知识库文件。

该文件用于支撑自然语言问答、产品推荐和选型逻辑说明，可用于回答用户关于国产 GPU / NPU 产品、应用场景和选型建议的问题。

news_data.json

本地新闻数据文件。

用于展示国产 GPU、AI 芯片、智算中心、大模型基础设施等相关行业动态。

news_api.json

新闻接口或新闻配置文件。

可用于后续扩展实时新闻能力，例如接入第三方新闻 API 或自定义行业资讯源。
